# ADLD-AAT: Digital Logic Design Suite

This repository contains a comprehensive suite of 12 digital logic modules implemented in **Verilog HDL**. Developed as an Alternative Assessment Task (AAT), this project focuses on hardware modeling, RTL design, and simulation using **Cadence EDA tools** in a Linux environment.

## 🚀 Project Scope
The suite covers foundational to advanced digital circuits, emphasizing efficient logic synthesis and robust testbench verification. Key implemented modules include:
* **4-bit Arithmetic Logic Unit (ALU)**
* **Barrel Shifter**
* **Counters** (Synchronous and Asynchronous)
* **Finite State Machines (FSMs)**
* *(Includes 8 additional combinatorial and sequential logic modules)*

## 🛠️ Tech Stack & Environment
* **Hardware Description Language:** Verilog HDL
* **EDA Tools:** Cadence (Digital Logic Simulation & Synthesis)
* **OS Environment:** Linux
* **Version Control:** Git *(Configured to exclude heavy Cadence simulation directories and intermediate binaries)*
    
## 📂 Repository Structure
* `src/` - Verilog RTL source files (`.v`)
* `tb/` - Simulation testbenches for verifying module behavior

## ⚙️ Usage & Simulation
To simulate these modules using your Cadence setup:
1. Clone this repository into your Linux workspace.
2. Compile the target Verilog source file and its corresponding testbench using your Cadence compiler.
3. Run the simulation and launch the waveform viewer to verify the logic transitions and timing.
